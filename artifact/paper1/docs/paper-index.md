# Paper-to-Lean index

This index follows the numbered statements in the compiled paper, **Every
Version Tells a Story: Verifying MRDTs Against Their Natural Specifications**.

Links identify the declaration's first source line. Line numbers refer to the
supplied source, including comments and blank lines. `P.` abbreviates
`Sal.MRDTs.Paper1.` and `M.` abbreviates `Sal.MRDTs.`. The
[interactive Lean guide](../Sal/Artifact/Guide.lean) checks the main declaration
names and provides the same reading order inside an editor.

The correspondence column distinguishes a definition, a sufficient checked
theorem, and a related result. A theorem with additional replay, metadata,
issuance or invariant premises is not an exact transcription of a shorter
paper display. The [claim map](claims-and-theorems.md) explains these domains;
the [datatype map](datatypes.md) identifies the selected instance endpoints.
