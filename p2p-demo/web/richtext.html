The document core is a mirror of machine-checked Lean proofs — and nothing more. What the document DOES is proven; the runtime adds no unproven behavior on the core side:

  • Rich-text semantics. How bold/italic/underline grow, how a link's end stays put, how overlapping comments coexist, how concurrent formatting resolves — the verified document-order Peritext read model (#55 → #110).
  • Convergence. The sequence CRDT (embedded-chain RGA) and its three-way merge converge every replica to one document.
  • Certified GC. Compaction shrinks the document's metadata only at a settled cut and preserves every read (the stability VC).
  • Cross-epoch merge. Two peers that compacted differently still merge to the same document — the mechanized epoch diamond (#112, kernel-clean).

The JavaScript runtime is a tested mirror of these proofs (checked against them, not extracted from Lean). The editor, the networking (relay / hub), the browser UI, and local storage are ordinary UNVERIFIED code — the untrusted shell around the verified core.
