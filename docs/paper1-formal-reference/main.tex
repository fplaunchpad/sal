\begin{abstract}
This reference accompanies \emph{Convergence Is Not Correctness: Verifying
Mergeable Replicated Data Types}. It follows the paper's operational semantics,
definition of RA-linearizability, merge proof, and sequential-specification
argument, using the same notation. It states the additional hypotheses needed
by the checked development: a justified state invariant, evidence from the
original issuer, and visibility between updates that conflict in the sequential
specification. These additions are identified where they enter the definitions.
Implementation equations retain concrete state equality.
\end{abstract}
\paragraph{How to read this reference.}
Sections 3--6 have the same titles and order as the paper's formal sections.
The motivation and literature discussion in Sections 1--2 of the paper are not
repeated. Definition and theorem numbers within sections are specific to this
reference because it makes additional premises explicit. Each main result names
its manuscript counterpart; Appendix~\ref{app:correspondence} gives a compact
cross-reference, followed by the optional Lean declaration map in
Appendix~\ref{app:traceability}. Reading the main text requires no Lean knowledge.
